Toy Library
No more duplicate gifts.

The mark

An open storybook — everything in the library is a story, whatever the platform — wearing a teal check badge: the “already have it” ✓ that is the whole point of the product. Coral for warmth and gift-wrap energy, teal for the check, deep indigo for the words.

Using it

  • Pair the mark with the wordmark in Fredoka 600, ink indigo — never recolor the book or the check.
  • Give it breathing room: at least the width of the check badge on every side.
  • Minimum size 16px — the book and check stay legible all the way down to the favicon.
  • On busy photos, sit it on the lavender wash or white, not directly on the image.

Type

Fredoka — headlines, wordmark, buttons

Nunito — everything else. Friendly and round, but grown-up enough for the parents who actually run the lists. “Never gift the same Tonie twice.”

Voice

  • Warm, plain, a little playful — written parent to parent.
  • We say gift-givers, never “users”; already have it, never “owned inventory”.
  • The enemy is the duplicate gift, never the grandparent who bought it.
  • Short sentences. One idea each. Exclamation marks are rationed — the checkmark does the celebrating.
